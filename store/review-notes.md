# MoviePlz — App Store review information

## App Review notes (paste into App Store Connect → App Review Information → Notes)

The review code isn't kept in this repository. The notes as sent, with the
real code, and the App Review contact are in `store/private.json`
(gitignored); below, the code reads `<review code>`.

MoviePlz has no accounts or passwords. People join a friend's list with a
five-digit invite code that the friend reads to them; normal codes work
once and expire after ten minutes.

To review as a friend, use the permanent review code:

    1. Open MoviePlz and tap "Join as a friend".
    2. Enter the code <review code> and tap Continue.
    3. Type any name and tap Continue, then "Start browsing".

You'll be in a demo list ("MoviePlz Demo") with about 25 well-known films
and series. Try: browse and search the Library (posters and descriptions
come from The Movie Database), open a title, and suggest something that
isn't there (Library → search → "Suggest …", or Home → "Suggest something").

To review as a host (the person whose list it is): from the welcome
screen tap "Set up as host" and type a name. You'll get your own empty
list and an invite code; tap "Go to my library", then "Add your titles"
and paste a few titles (one per line) to fill it.

Account deletion (Guideline 5.1.1(v)): friends tap "Leave this library"
at the bottom of Home; hosts tap "Delete my library" at the bottom of the
Dashboard. Both delete the person's name and suggestions immediately.

Notifications are used only for suggestions (a new suggestion for the
host; "up for it" and "saw it" for the friend who suggested).

Sign-in required: No (no accounts; the review code above gives access).

## App Privacy answers (App Store Connect → App Privacy)

Data used to track you: **No.**

Data collected, all **linked to the user**, **not used for tracking**,
purpose **App Functionality** only:

| Category | Type | Why |
|---|---|---|
| Contact Info | Name | The display name people type, shown to their list |
| User Content | Other User Content | Suggestions, notes, and the titles on a list |
| Identifiers | Device ID | Push notification token (only if notifications are allowed) |

Not collected: location, contacts, photos, health, financial info, browsing
or search history, purchases, usage data, diagnostics, advertising data.

Third parties: The Movie Database (titles only, for posters), Google
Sheets (a sheet the host links), Apple Push Notification service (iOS)
and Google Firebase Cloud Messaging (Android), which get the push token
only if notifications are allowed.

## Server settings this needs (Forge → movieplz.hypeapps.dev → Environment)

    MOVIEPLZ_REVIEW_CODE=<review code>   # 5 digits; reviewers join the demo list
    MOVIEPLZ_REVIEW_HOST="MoviePlz Demo"
    MOVIEPLZ_SUPPORT_EMAIL=lazarus@hypeapps.dev   # optional; already the default
    APNS_ENVIRONMENT=production
    TMDB_READ=…

Then run once (Forge → Commands): `php artisan movieplz:review-demo`
