# Code of conduct

MoviePlz is a small project. Be kind and assume good faith.

- Talk about the code and the app, not the person.
- No harassment, insults, or sexual or discriminatory language or images,
  in issues, pull requests, commits or anywhere else the project lives.
- Don't post other people's private information.
- Disagree by explaining why, and accept the maintainer's decision on what
  gets merged.

If someone breaks these rules, the maintainer may edit or remove what they
posted and block them from the repository.

To report a problem, email the address on
https://movieplz.hypeapps.dev/support. Reports are kept private.
